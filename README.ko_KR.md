아직 오브젝트 변형과 변형 애니메이션을 제대로 익히지 못했다면, 그것은 여러분의 잘못이 아닙니다. 도구가 충분히 쓰기 쉬워지지 않았을 뿐입니다. 이 도구는 가장 편리한 변형 경험을 제공할 것입니다.

## 빠른 시작

1. **설치:** [릴리스 페이지](https://github.com/AIGODLIKE/simple_deform_helper/releases)에서 다운로드합니다. 앞으로 Blender Extensions에서 직접 설치할 수 있게 할 예정이지만, 이미 많은 사용자가 이 도구를 쓰고 있으므로 충분한 실제 사례를 수집하고 안정성을 확인한 뒤 정식으로 게시하겠습니다.
2. **위치:** `N` 패널을 열고 **심플 디포머 V2** 탭을 찾습니다.
3. **추가:** 변형할 오브젝트를 선택하고(여러 오브젝트를 지원하지만 너무 많이 선택하지 마세요) **표준형 케이지 추가**를 클릭합니다.
4. **조작:** 케이지 컨트롤을 드래그합니다.
5. **애니메이션:** 아래쪽의 **키 삽입**을 클릭해 현재 상태를 기록합니다.
6. **베이크:** **메시 애니메이션 베이크**를 클릭해 한 번에 베이크합니다. 내보내기가 필요하거나 애니메이션 성능을 높이고 싶을 때 사용하세요.
7. 완료되었습니다. 다른 케이지 유형도 살펴보세요.

## 상세 매뉴얼

### 기능 정의

#### 변형 케이지

변형과 변형 범위를 더 직관적으로 보여 주기 위해 변형 케이지 개념을 사용합니다. 케이지 유형은 서로 다르지만, 오브젝트를 감싼 뒤 변형한다는 동작은 같습니다.

변형 케이지는 다음 네 종류입니다.

**표준형 케이지:** 다중 레이어 변형 케이지라고도 합니다. 구부리기, 비틀기, 늘리기, 전단 효과를 원하는 방식으로 조합해 변형을 만듭니다.

**전단형 케이지:** 오브젝트를 원하는 접선 방향으로 변형합니다.

**FFD형 케이지:** 래티스 변형을 강화한 유형으로 포인트, 에지, 면, 영향도 필드, 슬라이드까지 지원합니다.

**커브형 케이지:** 사람이 다루기 더 편한 커브 컨트롤로 오브젝트를 변형합니다.

#### 체인 케이지

여러 케이지를 구간별로 사용하면서 서로 연결해야 할 때 체인 케이지를 사용합니다. 예를 들면 교차 방지, 경계면 변형 연동, 변형 전달 등이 있습니다. 체인 케이지를 바로 만들 수도 있고, 먼저 변형 케이지를 만든 뒤 여러 체인 케이지로 세분할 수도 있습니다.

### 표준형 케이지

구부리기, 비틀기, 테이퍼, 늘리기, 전단 효과를 원하는 순서로 조합할 수 있습니다. 효과는 위에서 아래로 차례로 쌓입니다. 각 유형은 표준형 케이지 하나에 한 번만 넣을 수 있으므로 같은 효과가 여러 번 필요하면 표준형 케이지를 하나 더 추가하세요.

#### 구부리기

오브젝트를 원호 형태로 구부립니다.

| 파라미터 | 설명 |
|---|---|
| 구부리기 각도 | 구부리는 강도를 조절합니다. 360도이면 원이 됩니다. |
| 비틀기 각도 | 구부리기의 비틀림을 조절합니다. |

##### 중요: 올바른 구부리기 방향을 한 번에 설정

구부리기 방향이 잘못되었나요? 축 방향 전환 표시를 켜고 구부리기 방향 기즈모에서 방향을 선택하세요. 구부리기 축의 표시 우선순위가 가장 높기 때문에 다른 변형이 있어도 구부리기 방향이 먼저 표시됩니다.

##### 중요: 구부리기 시작 위치

기본 구부리기 시작 위치는 케이지 원점에 따라 정해지며 기본값은 아래쪽입니다. 위쪽, 중앙, 대칭을 선택할 수 있습니다. 대칭은 중앙에서 시작해 서로 반대 방향으로 구부립니다.

#### 비틀기

케이지 원점에서 시작해 아래에서 위 방향으로 오브젝트를 비틉니다.

| 파라미터 | 설명 |
|---|---|
| 비틀기 각도 | 비틀기 각도를 조절합니다. 360도마다 한 바퀴입니다. |

#### 테이퍼

오브젝트를 가늘어지거나 넓어지도록 변형합니다.

| 파라미터 | 설명 |
|---|---|
| 테이퍼 계수 | 테이퍼 강도를 조절합니다. |

##### 주의: 경계를 조절할 때 생기는 뾰족한 끝

테이퍼 계수를 특정 값(아래쪽: `-1`, 위쪽: `1`, 중앙: `2` 또는 `-2`, 대칭: `-2`)으로 설정하면 뾰족한 끝이 생깁니다. 이 끝에서는 메시가 완전히 닫혀 하나의 점이 됩니다.

끝의 위치에 따라 위쪽 또는 아래쪽 경계를 조절할 때 모델이 눌린 것처럼 보일 수 있습니다. 이것은 알고리즘 문제가 아닙니다. 닫힌 끝의 위나 아래에는 메시가 존재하지 않으므로 경계를 조절할 때 이 동작을 참고하세요.

<img width="2560" height="1380" alt="테이퍼 끝과 케이지 경계" src="https://github.com/user-attachments/assets/08e81591-af50-4909-915c-9d94c8903a8d" />

#### 늘리기

케이지 원점에서 시작해 아래에서 위 방향으로 오브젝트를 늘이거나 줄입니다.

| 파라미터 | 설명 |
|---|---|
| 늘리기 계수 | 늘리기 강도를 조절합니다. |
| 볼륨 유지 | 켜면 오브젝트의 부피가 제한됩니다. 길게 늘이면 가늘어지고 짧게 줄이면 납작해집니다. |

#### 전단

케이지 원점에서 시작해 아래에서 위 방향으로 오브젝트를 접선 방향으로 변형합니다.

| 파라미터 | 설명 |
|---|---|
| 전단 계수 | 케이지 로컬 X/Z 방향의 전단량을 조절합니다. |

### 전단형 케이지

표준형 케이지의 전단 효과와 같은 방식으로 동작합니다.

### FFD형 케이지

더 고급스럽고 조작하기 쉬운 래티스 변형입니다. 포인트, 에지, 면, 영향도 필드, 슬라이드까지 지원합니다.

#### 포인트／에지／면

Blender 기본 래티스 편집은 포인트를 사용합니다. FFD는 에지와 면 컨트롤도 추가하므로 항상 버텍스 기준으로만 생각할 필요가 없습니다.

#### 슬라이드

포인트, 에지 또는 면을 선택하고 `G`를 두 번 누르면 바로 슬라이드 모드로 들어갑니다. 슬라이드 방향은 포인터 아래에 있는 인접 에지나 단면에 따라 정해집니다.

#### 대칭

켜면 선택한 축을 기준으로 대칭 위치의 포인트, 에지 또는 면도 함께 선택됩니다.

#### FFD 포인트 수와 보간

래티스 포인트 수와 보간 방식을 설정합니다. 기본적으로 U/V/W 설정이 연동되며 연동을 끌 수 있습니다.

#### FFD 포인트 영향도(강력 추천)

거의 모든 3D 소프트웨어에서 FFD 포인트의 영향도는 동일합니다. 그래서 FFD로 오브젝트를 변형한 뒤 원래대로 되돌리는 단순한 애니메이션도 번거로울 수 있습니다. 여기서는 매번 래티스 형태를 바꾸는 대신 컨트롤 포인트의 영향도를 언제든 조절할 수 있습니다.

#### 편집 모드

**오브젝트 편집:** 케이지 컨트롤을 사용합니다. 컨트롤 기즈모를 선택하면 자동으로 시작되며 `Esc`, 빈 공간 더블클릭 또는 오른쪽 클릭으로 종료합니다.

**네이티브 편집:** Blender 기본 래티스 편집 모드로 들어갑니다. **네이티브 편집**을 다시 클릭하면 종료합니다.

#### 중공 FFD

켜면 바깥쪽 컨트롤만 표시하고 변형 계산에도 바깥쪽 컨트롤만 사용합니다.

#### 재설정

FFD를 기본 상태로 되돌립니다. 원래 상태로 복원하는 애니메이션이나 상태 초기화에 유용합니다.

### 커브형 케이지

오브젝트에 맞는 가이드 커브를 만들고, 그 커브로 변형을 제어합니다.

#### 모드 선택

| 모드 | 설명 |
|---|---|
| 커브 모드 | 가이드 커브가 우선합니다. 가이드가 케이지 크기를 바꿀 수 있으며 오브젝트는 가이드에 맞게 늘어나거나 줄어듭니다. |
| 케이지 모드 | 케이지가 우선합니다. 가이드는 케이지 크기를 바꾸지 않으며, 케이지는 생성 당시 가이드를 따라 갖고 있던 길이를 유지합니다. |

#### 현재 가이드 바인딩

오브젝트의 변형 상태만 재설정하고, 현재 가이드 형태를 기준으로 오브젝트를 다시 제어합니다.

#### 커브 닫기

켜면 가이드 커브를 닫습니다.

#### 볼륨 유지

켜면 길게 만들 때 가늘어지고 짧게 만들 때 굵어집니다.

#### 커브 컨트롤 파라미터(네이티브)

| 파라미터 | 설명 |
|---|---|
| 가이드 해상도 | 원본 커브의 해상도를 조절합니다. |
| 반지름 | 원본 커브 전체의 반지름을 조절합니다. |
| 비틀기 | 원본 커브 전체의 비틀기를 조절합니다. |

#### 가이드 프리셋

현재 커브를 프리셋 유형으로 바꿉니다. 오브젝트 형태가 달라질 수 있으니 주의하세요.

#### 커브 편집

**오브젝트 편집:** 사용하기 쉬운 기즈모로 가이드 커브를 편집합니다.

**네이티브 편집:** 가이드 커브의 Blender 기본 커브 편집 모드로 들어갑니다.

**재설정:** 원래 상태로 되돌립니다.

#### 포인트 수와 균등 분할

필요한 포인트 수를 선택한 다음 **균등 분할**을 클릭합니다. 커브는 형태를 최대한 유지하면서 기즈모 컨트롤 포인트를 추가합니다.

#### 커브 컨트롤 파라미터(활성 가이드 포인트)

| 파라미터 | 설명 |
|---|---|
| 포인트 비틀기 | 선택한 가이드 포인트의 비틀기를 설정합니다. |
| 포인트 반지름 | 선택한 가이드 포인트의 반지름을 설정합니다. |
| 비틀기 | 선택한 가이드 포인트의 비틀기를 설정합니다. |
| 전체 감쇠 | Blender 비례 편집 설정에 따라 현재 조작 포인트 주변에서 영향을 받는 포인트와 영향 강도를 정합니다. |

#### 단면

가이드 커브의 포인트 구간 외에도 케이지 자체에 구간을 추가할 수 있습니다. 기존 커브 변형 위에 케이지로 세부 조정을 더할 수 있어 가이드 포인트가 많을 때 특히 유용합니다.

### 체인 케이지

<img width="2560" height="1380" alt="체인 케이지 컨트롤" src="https://github.com/user-attachments/assets/4b1cad97-8ff4-4728-8c81-92f229255472" />

#### 공통 속성

오브젝트에 여러 구간의 변형이 필요할 때는 체인 케이지가 가장 좋은 선택입니다.

| 기능 | 설명 |
|---|---|
| 변형 상속 | 케이지 시작점부터 뒤따르는 각 구간으로 변형 컨트롤을 차례로 전달합니다. |
| 경계 연동 | 켜면 인접한 경계의 스케일 컨트롤이 서로 연동됩니다. |
| 경계 보호 | 인접한 케이지가 서로의 경계를 넘어가지 않도록 합니다. |

#### 생성 방법

**직접 추가:** 오브젝트 전체에 체인 케이지를 만듭니다.

**세분해서 추가(권장):** 기존 케이지를 선택해 세분합니다. 다음과 같은 상황에서 특히 유용합니다.

| 상황 | 방법 |
|---|---|
| 국소적으로 여러 변형기가 필요함 | 1. 일반 변형 케이지를 만듭니다. 2. 상태를 조절합니다. 3. **체인 케이지로 세분**을 클릭합니다. |
| 현재 상태를 유지하며 여러 구간을 조절하고 싶음 | **체인 케이지로 세분**을 바로 클릭합니다. 알고리즘이 현재 형태를 유지합니다. |

#### 주의 사항

1. 체인 케이지를 너무 많이 만들면 성능이 떨어집니다. 4개가 넘는 구간이 필요하면 아마튜어 사용을 고려하세요.
2. 오브젝트 하나에 여러 케이지가 있을 때는 다른 케이지를 숨겨 뷰포트 부하를 줄일 수 있습니다.

### 편의 기능

#### 복사

오브젝트의 현재 형태를 기준으로 변형 스택에 같은 상태의 복사본을 만듭니다.

#### 미러

현재 형태를 기준으로 선택한 축 방향의 미러 복사본을 만듭니다.

### 원클릭 애니메이션

번거로운 애니메이션 작업을 쉽게 하기 위해 세 개의 버튼을 제공합니다.

| 버튼 | 설명 |
|---|---|
| 키 삽입 | 현재 상태를 한 번에 기록합니다. |
| 키 삭제 | 타임라인의 현재 프레임에 있는 변형 관련 애니메이션 키를 삭제합니다. 현재 프레임 위치를 확인하세요. |
| 메시 애니메이션 베이크 | 현재 오브젝트의 메시 애니메이션을 한 번에 베이크합니다. 내보내기가 필요하거나 애니메이션 성능을 높이고 싶을 때 사용합니다. |

### 레거시 유형

새 버전은 이전 버전의 기능을 완전히 다시 구현하고 그 이상으로 확장했습니다. 하지만 지오메트리 노드의 복잡성을 선호하지 않는 사용자도 많기 때문에 레거시 유형을 계속 제공합니다.

자세한 사용법은 이전 버전을 참고하세요.

### 여러 오브젝트 사용

1. **생성:** 여러 오브젝트를 선택하고 **케이지 추가**를 클릭하면 하나의 변형 결과로 병합됩니다.
2. **편집:** 병합된 오브젝트를 더블클릭하면 편집 모드로 들어갑니다. 편집 모드에서는 개별 오브젝트에 케이지를 추가할 수 있습니다.
3. **병합 해제:** 병합을 해제하면 병합 오브젝트와 그 위의 변형기가 삭제됩니다.
4. **적용 및 베이크:** 여러 오브젝트 결과를 적용하거나 베이크해도 원본 오브젝트에는 영향을 주지 않습니다.

## 호환성

| 항목 | 지원 상태 |
|---|---|
| Blender | **5.0.0 이상** |
| 케이지 대상 | 메시, 커브, 표면, 텍스트. |
| 병합 원본 | 메시, 커브, 표면, 텍스트, 메타볼, 헤어 커브, 포인트 클라우드. |
| 래티스 | 레거시 Simple Deform만 지원하며 명확한 안내가 표시됩니다. |
| 엔진 | 케이지는 지오메트리 노드, 레거시 모드는 Blender 기본 Simple Deform을 사용합니다. |
| 언어 | 영어, 중국어 간체, 일본어, 한국어. |

## 자주 묻는 질문

| 증상 | 확인 사항 |
|---|---|
| 구부리기 방향이 잘못되었거나 효과가 없음 | 축 방향 전환 표시를 켜고 구부리기 방향을 선택합니다. |
| **심플 디포머 V2** 탭이 없음 | 확장이 켜져 있는지 확인하고 3D 뷰에서 `N`을 누릅니다. 이전 버전을 교체한 뒤에는 Blender를 한 번 재시작하세요. |
| 케이지를 추가해도 효과가 없음 | 오브젝트 모드에서 지원 오브젝트를 선택했는지 확인합니다. 복제된 오브젝트에서 노드 스테이지가 사라졌다면 잘못된 스테이지를 삭제하고 다시 추가합니다. |
| 재생해도 메시가 움직이지 않음 | 케이지 파라미터에 실제로 키가 들어 있는지 확인합니다. 최소 두 프레임에서 **키 삽입**을 클릭하세요. 애니메이션 파일은 열 때 자동으로 다시 동기화됩니다. |
| 구부린 면이 각져 보임 | 케이지 스테이지 앞에서 변형 축 방향으로 지오메트리 세그먼트를 추가합니다. |
| 케이지가 오브젝트와 맞지 않음 | 스테이지를 선택해 축을 설정한 다음 **정렬 및 맞춤** 또는 **체인 정렬 및 맞춤**을 클릭합니다. |
| 체인에 이음새가 보임 | **자동 재연결**을 켜고 **체인 다시 연결**을 클릭한 뒤 **앞 간격**과 이음새 끝의 스케일을 확인합니다. |
| 핸들이 보이지 않음 | 대상 또는 케이지와 해당 변형 레이어를 선택한 뒤 구부리기 경향, 비틀기 표시, 끝단, 길이 옵션을 켭니다. |
| 래티스에 케이지를 추가할 수 없음 | 의도된 제한입니다. **Simple Deform 추가(레거시)**를 사용하세요. |

## 데이터 및 제거

케이지 스테이지를 삭제하면 그 스테이지가 관리하는 지오메트리 노드 모디파이어와 헬퍼 오브젝트도 함께 삭제됩니다. 확장을 제거해도 기존 `.blend` 파일에 생성된 노드 그룹은 자동으로 사라지지 않습니다. 먼저 **변형 스택 제거**를 실행한 뒤 복사본을 저장하세요.
